# Mario character image library

This folder is used by a private, non-commercial family game prototype.

- Character names and artwork belong to Nintendo and their respective rights holders.
- Most new assets were selected from the representative page images on Super Mario Wiki; the exact source page for every character is recorded in `manifest.json`.
- Ten images were already present in the earlier Big Star prototype and are marked as `existing-project-asset` in the manifest.
- These files must not be treated as original project artwork or as freely licensed assets.

The game must reference the local files in this folder rather than hotlinking third-party image URLs.
